Обновление поверх старых версий работает

Сертификат не менялся — просто скачайте и установите поверх. Приложение также само предложит обновление через «Доступно обновление» (OTA). Сайт, APK и OTA имеют один счётчик версий: 22. Дальше только +1.

Постоянный адрес сайта

Сайт живёт на GitHub Pages — бесплатный хостинг с постоянным адресом. Больше ничего не ломается по ночам: этот адрес не меняется и не зависит от временных площадок.

Как установить

  1. Нажмите «Скачать приложение» — файл попадёт в «Загрузки».
  2. Откройте файл — Android спросит разрешение на установку из этого источника, разрешите.
  3. Установите поверх старой версии и откройте Z.ai.

Что нового в версии 17
